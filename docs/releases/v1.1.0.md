# Kas Will v1.1.0

## English

- Experimental mainnet support with a visible Mainnet / TN10 switch; new installations default to mainnet. Existing plans are never migrated automatically.
- Wallet context, token registrations and pending transactions are isolated by network. Switching disconnects the wallet and clears pending signing state.
- Official SilverScript v1.0.0 compiler and Kaspa 2.1.0 local preflight engine. Stable contracts use KCC-1 dispatch tags, BLAKE3 template hashes and DAA-based age.
- KCC20 Final inheritance for the pinned six-field reference implementation: fund, check in, owner recovery and mature distribution to 1–3 heirs. This does not support arbitrary issuer templates or minters. Legacy four-field tokens remain TN10-only.
- Portable multi-device will packages, direct-node operation and optional Kascov visualization remain available. Websites are not required.
- Real-KAS confirmation dialogs, a default 1 KAS deployment/plain-transfer cap and `ALLOW_MAINNET=false` emergency disable switch.
- Native macOS Apple Silicon DMG, Windows x64 installers and Linux x64 DEB/AppImage; platform SHA256 files are included.

**Experimental and not independently audited.** Tests do not establish mainnet safety. No live-chain transaction is performed by the release tests. Use small values, verify backups and recovery, and review every transaction. Maturity requires someone to submit a transaction; owner-authorized spends can still compete until the UTXO is spent.

Packages are not signed by an Apple Developer ID or Windows Authenticode certificate (macOS may carry an ad-hoc signature). Do not disable system security or install unofficial DLLs. Windows uses the system WebView2 runtime; Linux needs the system WebKitGTK 4.1 runtime. This is not a fully dependency-free portable application.

Verification: 72 application tests and 60 local-engine Rust tests passed locally. Each release build also runs application tests and packaged-service checks, including actual compilation with the bundled stable compiler. Linux service checks are not a full graphical desktop validation.

## 中文

- 开放主网实验功能，提供醒目的主网 / TN10 切换；新安装默认主网，已有计划不会自动迁移。
- 钱包上下文、代币登记和未完成交易按网络隔离；切换网络断开钱包并清除待签状态。
- 固定官方 SilverScript v1.0.0 编译器与 Kaspa 2.1.0 本地预检引擎，适配 KCC-1 入口标签、BLAKE3 模板哈希与 DAA 年龄。
- 新增固定六字段参考实现的 KCC20 Final 继承：入金、签到、拥有者取回、1–3 位继承人到期分配。不承诺支持任意发行方模板或 minter；旧四字段代币仅限 TN10。
- 保留多人跨设备操作包、直连节点与可选 Kascov 可视化；不依赖网站在线。
- 增加真实 KAS 确认弹窗、默认 1 KAS 部署/普通转账上限及 `ALLOW_MAINNET=false` 应急关闭开关。
- 提供 macOS Apple Silicon DMG、Windows x64 安装包、Linux x64 DEB/AppImage，以及各平台 SHA256 校验文件。

**主网为未经独立审计的实验功能。** 测试通过不代表主网安全就绪；发布测试不会发起真实链上交易。请先小额验证备份、恢复及完整流程。到期需要有人提交交易；UTXO 被支出前，拥有者授权操作仍可能与继承分配竞争。

安装包未使用 Apple Developer ID 或 Windows Authenticode 证书签名（macOS 可能含临时签名）。不要关闭系统安全保护或安装来历不明的 DLL。Windows 依赖系统 WebView2，Linux 依赖系统 WebKitGTK 4.1，不是完全零依赖便携程序。

本地验证通过 72 项应用测试及 60 项 Rust 引擎测试。各平台构建还执行应用测试和打包后服务检查，包括调用包内正式编译器真实编译；Linux 服务检查不等于完整桌面图形运行验证。
