# Kas Will v1.0.0

- 1.0.0 marks the first feature-complete milestone of the local-first Kaspa inheritance planner: one-click check-in renewal, KAS and experimental KCC20 wallet transfers, strict backup-gated deletion, and second-precision maturity countdowns are all in place.
- Fixed the lifecycle card flashing endlessly after a plan matured.
- The Chinese UI now calls the feature 资产继承计划 (asset inheritance plan) instead of 遗嘱 everywhere except the legal disclaimer; the English UI keeps the neutral "will" and the Kas Will brand is unchanged.
- Node operations are dramatically faster: the local service keeps one warm wRPC connection per network and pre-warms TN10 at startup; every long-running action shows live progress and mutating operations run one at a time.
- Check-in renewal is a single guided flow that builds, shows the fee, signs after the wallet password, broadcasts, and waits for the node to confirm before resetting the countdown. Renewal rejections are bilingual.
- The wallet page gains KAS send and experimental KCC20 support: register a token once with the issuer descriptor and the current redeem program, see advisory Kascov balances, and send KCC20 with the current cell verified against the node's P2SH script hash. KCC20 plan creation can pick a registered token.
- Portable operation packages follow the covenant automatically — import once on another device; owner renewals never require a re-export.
- Operated plans are deletable locally only after a fresh package backup (save location hand-picked every time) plus typing `DELETE LOCAL WILL RECORD`; the service independently verifies the backup commitment.
- New Kaspa-style app icon across every platform package and the web favicon.
- Mainnet transactions remain disabled. TN10 experimental only. This is a technical tool, not a substitute for a legal will, legal advice, key backups, or an independent security audit.

# Kas Will v1.0.0（中文）

- 1.0.0 是本地优先的 Kaspa 资产继承计划第一个功能完整里程碑：一键签到续期、KAS 与实验性 KCC20 钱包收发、严格备份删除、秒级到期倒计时全部就绪。
- 修复继承计划到期后生命周期卡片持续闪烁的问题。
- 中文界面全面改称“资产继承计划”（法律声明中指真实遗嘱处保留原词）；英文界面保留中性的 "will"，Kas Will 品牌名不变。
- 节点操作大幅提速：本地服务按网络保持常驻 wRPC 连接并在启动时预热 TN10；所有耗时操作显示实时进度，变更类操作同一时间只允许一个。
- 签到续期为一键引导流程：自动构建、显示手续费、输入钱包密码签名广播，等待节点确认后才重置倒计时；续期被拒时中英双语说明原因。
- 钱包页新增 KAS 发送与实验性 KCC20 支持：粘贴发行方 descriptor 和一次当前 redeem program 即可登记代币，显示 Kascov 参考余额，发送前用节点 P2SH 脚本哈希验证当前单元；创建 KCC20 计划时可直接选择已登记代币。
- 便携操作包自动跟随 Covenant——其它设备导入一次即可，建立人续期后无需重新导出。
- 操作过的计划只有在另存新备份（每次手动选择保存位置）并输入 `DELETE LOCAL WILL RECORD` 后才能从本机删除；服务端独立校验备份承诺。
- 全新 Kaspa 风格应用图标，覆盖全部平台安装包与网页 favicon。
- 主网交易保持关闭，仅限 TN10 实验使用。本工具不替代法律遗嘱、律师意见、密钥备份或独立安全审计。
