# Kas Will v0.2.0

- Fixed imports of `.ssinvite` operation packages exported from wills created before the single-heir template change. Retired contract sources now ship in the app pinned by SHA-256; inspection accepts exactly those revisions while keeping commitment, compiler, artifact-hash and on-chain Covenant checks strict.
- Exports label their template revision and warn bilingual users when a package needs a compatible client; successful imports show the matched revision.
- Wills can be named at creation for the local list and package display only; names never change on-chain rules.
- Mainnet transactions remain disabled. TN10 experimental only.

# Kas Will v0.2.0（中文）

- 修复旧版本创建的遗嘱导出的 `.ssinvite` 操作包无法导入的问题。退役契约源码随应用内置并固定 SHA-256；导入端只接受这些显式历史修订，承诺校验、编译器、产物哈希与链上 Covenant 核验全部保持严格。
- 导出时标注模板版本，并在需要兼容客户端时给出中英双语提示；导入成功后显示匹配到的版本。
- 创建遗嘱时可命名，仅用于本机列表和操作包显示，不改变链上规则。
- 主网交易保持关闭，仅限 TN10 实验使用。
