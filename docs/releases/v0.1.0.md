# Kas Will v0.1.0

Kas Will is a local-first, bilingual Kaspa inheritance desktop application. This first public build is experimental and restricted to testnet-10.

## Highlights

- One to five inheritors with exact 100% allocation, including a single-inheritor 100% path.
- Owner check-in, owner recovery, and permissionless mature distribution enforced by SilverScript.
- Experimental TN10 KCC20 funding, recovery, and atomic inheritance distribution with Covenant ID, template, state, ownership, amount, and non-minter checks.
- Optional Kascov token-name lookup for display. Kascov metadata is never used as transaction authorization or token identity.
- Automatic Kaspa Resolver discovery plus saved local or custom `ws://` / `wss://` wRPC node settings and pre-save connection tests.
- Will-specific `.ssinvite` exports that are commitment-checked and recompiled on import, then opened directly in the Check in & claim screen with wallet-role-aware actions.
- Clear success/failure dialogs for creation and lifecycle operations, plus automatically refreshed Kascov deployment evidence and explorer links.
- A visible `Kas Will v0.1.0` version label in the main interface.
- Bundled compiler and local Kaspa script-engine preflight; covenant operation remains possible when websites are unavailable.
- Chinese and English UI with automatic locale detection.

## Security status

- SilverScript compiler: `023c7eed6b85038c72233a62024c5476640445e3`
- Network policy: TN10 only; mainnet signing and broadcast are disabled.
- This software is experimental and is not a legal will or a substitute for independent review.

## 中文摘要

Kas Will v0.1.0 支持 1–5 位继承人、签到续期、拥有者取回、到期触发继承、TN10 实验性 KCC20 原子继承、本地或自定义节点设置，以及每份遗嘱独立导出的跨设备 `.ssinvite`。导入时会重新验证固定模板与编译产物，并按钱包身份只显示建立人操作或到期提取；创建、部署和提取均有明确弹窗，部署后自动刷新 Kascov 收录结果。主网交易保持关闭。
